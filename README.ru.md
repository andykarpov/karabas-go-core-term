# term — современный терминал для Karabas Go / Mini / Mini G

[English version](README.md)

Терминал для плат семейства Karabas Go (Xilinx Spartan-6 XC6SLX25): софт-процессор VexRiscv (RV32IM) на 65 МГц
выполняет прошивку терминала на C ([libvterm](https://www.leonerd.org.uk/code/libvterm/) и свой экранный слой), RTL
рисует текстовый экран. Telnet и SSH идут через модуль ESP8266 на плате (его штатная AT-прошивка); USB-порт платы
соединяет терминал с ПК.

| Плата | Файл ядра | Видео | Звонок |
|---|---|---|---|
| Karabas Go | `term.kg` | VGA 1024 x 768 | I2S ЦАП (PCM5102) |
| Karabas Mini | `term.kg` | HDMI 1024 x 768 | HDMI, аналоговый выход (сигма-дельта) |
| Karabas Mini G | `term.kg` | HDMI 1024 x 768 | HDMI, I2S ЦАП |

Состояние: проверено на Mini G (USB serial, telnet, SSH, кодировки, телефонная книга, вкладки, мышь). Сборки для Go и Mini на платах
ещё не запускались.

## Возможности

- **Эмуляция:** `TERM=xterm-256color`: 256 цветов и truecolor, жирный / курсив / подчёркивание / мигание / инверсия /
  зачёркивание, альтернативный экран, области прокрутки, клавиши xterm, bracketed paste, мышь xterm.
- **Экран:** 1024 x 768 при 60 Гц, знакоместа 8 x 16 точек: полоса вкладок и сеанс 128 x 47; ~200 строк истории
  на вкладку.
- **Вкладки:** 4 сеанса сразу (один из них может быть USB serial), у каждого свой экран и история.
- **Мышь:** указатель, щелчки по полосе вкладок, мышь xterm для приложений, колесо.
- **Unicode:** UTF-8, широкие символы (CJK), комбинируемые знаки; глифы [GNU Unifont](https://unifoundry.com)
  (вся базовая многоязычная плоскость — с файлом шрифта на SD-карте; латиница, греческий, кириллица, псевдографика,
  блоки, Брайль и другое — и без него).
- **Подключения:**
  - **SSH** через ESP8266: свой небольшой клиент на [Monocypher](https://monocypher.org): обмен ключами
    curve25519-sha256 (strict kex), ключи серверов ssh-ed25519, шифр chacha20-poly1305; вход по ключу (ed25519),
    по паролю или keyboard-interactive; known_hosts и ключ пользователя хранятся на SD-карте;
  - **telnet** через ESP8266 (тип терминала, размер окна, двоичный режим);
  - **raw TCP** через ESP8266;
  - **USB serial**: порт ядра платы, `-if02` (getty или последовательная консоль на ПК).
- **Кодировки** старых машин и BBS: UTF-8, CP437, CP866, KOI8-R, CP1251, ISO-8859-1.
- **Телефонная книга** на SD-карте: удавшиеся подключения (64) с протоколом, портом, пользователем и кодировкой.

Не сделано: ключи серверов RSA / ECDSA (только ssh-ed25519: он есть в OpenSSH с 2014 года и в Dropbear с 2020-го),
проброс портов, выделение текста мышью.

## Как начать

1. Скопируйте `src/term.kg` (один файл для Go, Mini и Mini G) в корень SD-карты, а шрифт `sd/term/font.bin` — в
   `/term/font.bin` на карте.
2. Для telnet и SSH: один раз подключите ESP8266 к своему Wi-Fi в boot-ядре (**Setup Wi-Fi**). Ядро term пользуется
   этим подключением и никогда не меняет настройки, сохранённые в модуле.
3. Выберите term в меню ядер. Откроется экран подключения; на полосе вкладок над ним — IP-адрес модуля.

В OSD (**Menu+Esc**; «Menu» — клавиша Windows) — файл шрифта (**Font**, Menu+F1, загружается при старте) и **Reset**.

## Экран подключения

| Клавиша | Действие |
|---|---|
| ↑ ↓ / Tab | следующее поле |
| ← → | сменить Protocol / Charset |
| Enter | подключиться (на записи книги — к ней) |
| Del | удалить запись книги |
| Esc | назад к сеансу |
| Scroll Lock | открыть этот экран из сеанса (и обратно) |
| F8 | отключиться |
| F2 | ввести свой публичный ключ SSH в сеанс |

Поля: **Protocol** (SSH / telnet / raw TCP / USB serial), **Host** (имя или IP-адрес), **Port** (22 / 23 по протоколу),
**User** (SSH; пусто — спросит при входе), **Charset**.

В сеансе **Shift+PgUp / Shift+PgDn** листают историю; любая другая клавиша возвращает к экрану.

## Вкладки и мышь

| Клавиша | Действие |
|---|---|
| Ctrl+Shift+T | новая вкладка (откроется её экран подключения) |
| Ctrl+Shift+W | закрыть вкладку (с сеансом — сначала вопрос, Y / N) |
| Ctrl+PgUp / Ctrl+PgDn | предыдущая / следующая вкладка |
| Ctrl+Shift+1..4 | вкладка 1..4 |

На полосе — вкладки (номер и хост; `•` — новый вывод или звонок, пока вкладка не на экране), `×` закрывает вкладку,
`+` открывает новую; щелчок по вкладке показывает её, колесо над полосой листает вкладки. Указатель прячется через
3 с без движения и при наборе. Колесо в сеансе: приложению, если оно следит за мышью; иначе на основном экране
листает историю, на альтернативном (less, vim, man) шлёт стрелки.

## SSH

- При первом подключении к хосту показывается отпечаток его ключа, как у OpenSSH (`ED25519 key fingerprint is
  SHA256:...`): сравните его с `ssh-keygen -lf /etc/ssh/ssh_host_ed25519_key.pub` на сервере и ответьте `yes`.
  Если ключ хоста потом сменится — предупреждение OpenSSH; принять новый ключ можно только словом `replace`.
- Пароль и ответы keyboard-interactive вводятся в окне сеанса без эха; Ctrl+C — отмена.
- **Вход по ключу:** ядро делает свой ключ ed25519 при первом SSH-подключении; на экране подключения — его отпечаток.
  Войдите один раз по паролю, в shell наберите `echo '`, нажмите **Scroll Lock**, **F2** (строка ключа введётся),
  затем `' >> ~/.ssh/authorized_keys` и Enter. Дальше вход без пароля.
- Ключи лежат в save-файле ядра, `/term/font.sav` на SD-карте (вместе с телефонной книгой), без шифрования, как
  `~/.ssh/id_ed25519` без парольной фразы: не отдавайте карту чужим.
- Случайность для ключей — из моментов нажатий клавиш, движений мыши и событий сети, смешанных с seed из того же
  файла; при самом первом запуске нажмите несколько клавиш перед первым SSH-подключением.

## USB serial

Плата показывает на ПК два последовательных USB-порта (прошивка v26111901 и новее). Ядро работает со вторым,
`/dev/serial/by-id/usb-Karabas_Go_*-if02` в Linux — чистый поток байтов. Приглашение входа на ПК, например:

```
sudo agetty -L 115200 /dev/serial/by-id/usb-Karabas_Go_<serial>-if02 xterm-256color
```

(скорость на USB-порту не важна). На экране подключения выберите **USB serial**.

## Сборка

ISE 14.7 (`src/Makefile`: `make go`, `make mini`, `make minig`), RISC-V GCC от xPack для прошивки
(`make -C src/fw hw`, `make rom`). Тесты без платы: `src/sim/run_f3_host.sh` (клиент SSH против тестового сервера,
python3-asyncssh), `src/sim/run_f1.sh`, `run_f2.py`, `run_f3.py` (SoC в Verilator). Топы Go и Mini делаются из топа
Mini G скриптом `src/tools/mktops.py`. План и решения: [docs/PLAN.md](docs/PLAN.md).
